# Task 3: Data Visualization & Storytelling

## Project Overview
This project builds an executive Business Intelligence (BI) dashboard to analyze multi-channel retail profitability and sales dynamics using Python (`matplotlib` and `seaborn`).

## Visualizations Included
1. **Growth Trends:** Dual-line chart of monthly revenue vs. net profit.
2. **Customer Segmentation:** Donut chart evaluating segment contributions (Consumer, Corporate, Home Office).
3. **Category Breakdown:** Horizontal bar comparison of revenue vs. profit across merchandise categories.
4. **Regional Profit Margin:** Box plot distribution tracking margin consistency across geographic territories.
5. **Discount Erosion Analysis:** Regression scatter plot demonstrating margin degradation under heavy discounts.

## Strategic Takeaways
- **The 20% Discount Cliff:** Discounts exceeding 20% severely erode unit margins, often resulting in net losses.
- **Technology Margin Dominance:** Technology drives the highest total net profit despite moderate volume.
